# Refined LLC — Corporate Website

Sitio web corporativo de alto rendimiento construido con **Next.js 14 (App Router)**, **TypeScript** y **Tailwind CSS**.  
Diseñado como una **aplicación estática moderna**, rápida y optimizada para SEO.

---

## 🚀 Stack Tecnológico

- ✅ Next.js 14 (App Router)
- ✅ TypeScript
- ✅ Tailwind CSS
- ✅ Renderizado estático (SSG)
- ✅ Contenido gestionado por archivos JSON
- ✅ Optimización de imágenes local
- ✅ Diseño responsive y accesible
- ✅ Deploy en Vercel

---

## 📋 Requisitos

- Node.js 18+
- npm
